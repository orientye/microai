== 新手速通（零基础先看）

本节几乎不出现公式。目标：用类比搞清 *CartPole 在干什么*、*DQN 和 PPO 差在哪*、*代码从哪读起*。

=== 用一句话讲完

小车上立着一根杆。你每一步只能选「推左」或「推右」。杆立得越久，分数越高。AI 要自己学会怎么推。

环境名字叫 `CartPole-v1`：撑满 *500* 步算满分；杆倒或车出界则本局结束。
https://gymnasium.farama.org/environments/classic_control/cart_pole/

----

----

=== 两条学习路线：食堂选菜

*DQN（价值学习）* +
先估「这个局面下，左推 / 右推分别大概值多少分」，再选分高的。 +
像：先给每道菜打分，再点最高分那道。

*PPO（策略学习）* +
直接学「这种局面下更常选左还是右」。 +
像：不先打分，直接改点菜习惯——上次这么点结果不错，下次多点一点。

[NOTE]
====
*一句话对照：* DQN 学「值不值」；PPO 学「常不常选」。两条路都能玩通 CartPole，本仓库各有一版实现。
====

=== 最小流程图（无公式）

----
看到车和杆的状态（位置、速度、角度……）
        │
        ▼
选左或右（有时故意乱选 = 探索，免得只会一种推法）
        │
        ▼
杆还在？ → 得 1 分；倒了 / 超时？ → 本局结束
        │
        ▼
把「刚才那样推好不好」记下来，改一点脑子里的规则
        │
        ▼
重复很多局，直到经常能撑很久（例如近 10 局均分很高）
----

== 1. 手推一轮 DQN `train_step`

*本节一句话：* 用两个假样本，走一遍「算出当前分 → 算出老师给的目标分 → 算差距 → 改网络」。

对应 link:cart-pole-dqn/cartpole_train.py[`cartpole_train.py`] 中 `DQNAgent.train_step`。

假设 `BATCH_SIZE=2`，`GAMMA=0.99`：

[cols="1,2,1,1,2,2,2",options="header"]
|===
|i |已执行动作 stem:[a] |stem:[r] |done |policy stem:[Q(s)] |policy stem:[Q(s')] |target stem:[Q(s')]

|0
|1（右推）
|1
|0
|`[2.0, 3.0]`
|`[5.0, 1.0]` → 选 0
|`[3.0, 4.5]`

|1
|0（左推）
|1
|1（杆倒）
|`[1.5, 0.8]`
|任意
|任意
|===

*当前 Q（gather 真实动作）*

* i=0 → stem:[Q=3.0]；i=1 → stem:[Q=1.5]

*Double DQN 目标*

* i=0：policy 选 stem:[a^*=0]，target 估 stem:[3.0] → stem:[y_0=1+0.99\times 3.0=3.97]
* i=1：`done=1` → stem:[y_1=1]（切断 bootstrap）

*同批数字对照（勿把「裸」与「经典」混为一谈）*

* *经典 target-max*（选估都用 target）：stem:[y_0=1+0.99\times\max(3.0,4.5)=5.455] — 本例 policy 的 argmax 与 target 的 argmax *不一致*，故与 Double 拉开
* *单网 max*（无 target / 选估同一套在线网）：stem:[y_0=1+0.99\times\max(5.0,1.0)=5.95] — 更易虚高

（若 policy 与 target 的 argmax 碰巧相同，Double 与经典 target-max 的 stem:[y] 会相等；要演示过估计差异，需像上表这样分开。）

*损失（MSE mean 量级，按 Double 的 stem:[y]）*

[stem]
++++
L_{\mathrm{mean}} = \frac{(3.0-3.97)^2+(1.5-1)^2}{2} \approx 0.60
++++

（与 PyTorch `mse_loss` 默认 `mean` 一致；有的教材在 MSE 前写 stem:[1/2]，仅差常数倍，不影响 Adam 方向。）

反传只更新 `policy_net`：样本 0 抬高「右推」的 Q，样本 1 压低「左推」的 Q；随后 soft update 渗一点进 `target_net`。

*一句话：* `train_step` = 用慢半拍的价值表当老师，纠正当前表对已走动作的打分；探索在 `choose_action`，不在这一步。

[NOTE]
====
本仓库 DQN / PPO 均写 `done = terminated or truncated`，再用 `(1-done)` 关掉 bootstrap。 +
对 *terminated*（杆倒 / 车出界）正确；对 *truncated*（撑满 500 步）偏保守——杆其实还立着，严格 MDP 仍应 bootstrap。实现简单，会略低估「满分局」的后续价值。详见 link:cart-pole-dqn/README.md[`cart-pole-dqn/README.md`]。
====

== 2. Soft Update 为何比硬拷更稳

*本节一句话：* 标准答案本（target）不要一夜换新，每步只抄一点点在线网，训练更稳。

每步：

[stem]
++++
\theta^{-} \leftarrow \tau\theta + (1-\tau)\theta^{-},\quad \tau=0.005
++++

[cols="1,2,2",options="header"]
|===
| |硬更新（每 N 局整表拷贝） |软更新（本仓库现状）

|标签变化
|阶跃猛跳
|连续挪动

|TD 目标
|平台期稳、切换瞬间抖
|始终慢半拍、更平滑

|过估计耦合
|切换后老师突然变「激进学生」
|老师是近期 stem:[\theta] 的 EMA

|调参
|要选 `TARGET_UPDATE`
|`TAU` = 跟踪速度
|===

stem:[\tau=0.005] 时，从 0 追到约 0.5 大约要 stem:[\ln 0.5/\ln 0.995\approx 138] 步。代价是略慢；CartPole 上通常值得。`TARGET_UPDATE` 在训练脚本里已是遗留常量。

== 3. 信用分配：第 80 步倒地，第 10 步怎么背锅？

*本节一句话：* 杆很晚才倒，早期那一推也要被追责——但 DQN、REINFORCE、PPO 追责的方式不一样。

设定：人话「第 80 步倒下」↔ 转移下标 stem:[t=79]（0-based，下图同）；关心「第 10 步」↔ stem:[t=10] 的「右推」。

=== 3.1 DQN：TD 骨牌，不是一次 stem:[\gamma^{70}]

每次更新只改当前转移：

[stem]
++++
Q(s_t,a_t)\leftarrow r_t+\gamma Q_{\mathrm{target}}(s_{t+1},a^*)
++++

终局步 `done=1` → 目标纯 stem:[r]。stem:[Q(s_{79},\cdot)] 变差后，再抽到 stem:[t=78] 时目标跟着降，沿时间反向渗。
理论深度约 70 次 bootstrap；stem:[\gamma^{70}\approx 0.99^{70}\approx 0.49]。早期动作信号弱，还依赖 Replay 反复抽到链上的转移。
（本仓库把 `truncated` 也标成 `done`，满分截断处同样切断；见 §1 末注。）

=== 3.2 REINFORCE：整局标量一次乘上

[stem]
++++
\nabla J \propto G_{10}\,\nabla\log\pi(a_{10}\mid s_{10})
++++

stem:[G_{10}] 含第 10 步之后所有回报。优点：第 10 与第 80 步同次见面；缺点：方差极大。

=== 3.3 PPO + GAE：多步 TD 折中

[stem]
++++
\delta_t=r_t+\gamma V(s_{t+1})(1-d_t)-V(s_t)
++++

[stem]
++++
A_t=\delta_t+\gamma\lambda(1-d_t)A_{t+1}
++++

stem:[A_{10}] 含 stem:[(\gamma\lambda)^{69}\delta_{79}] 量级的远期残差。stem:[\lambda=0.95]：比纯 MC 方差小，比单步 TD 传得远。

----
t:     10        11    ...    79(倒)
DQN:   Q10 ←…多次采样渗…← Q79 ← r (done 切断)
REIN:  logπ10 * G10（一次）
PPO:   A10 = δ10 + γλ δ11 + … + (γλ)^69 δ79
----

== 4. 过估计：裸 max DQN vs Double（实验菜单）

*本节一句话：* 「取最大 Q」容易把分估虚；Double DQN 用一套网选动作、另一套网打分，缓解虚高。

=== 4.1 机制

目标含 stem:[\max_{a'}Q(s',a')] 时，噪声下 stem:[\max] 偏向偶发偏高的动作 → Q 系统性虚高。
Double：在线网选 stem:[a^*]，目标网估值。

=== 4.2 最小对照

固定环境 / 网络 / replay / ε / seed，只改目标构造：

[cols="1,2,2",options="header"]
|===
|变体 |选 stem:[a^*] |估值网

|单网 max（裸）
|`policy.argmax`
|同一 `policy`（无独立 target，或选估都不拆）

|经典 target-max
|`target.argmax`
|同一 `target`（有慢更新老师，但仍是 max 耦合）

|Double（现状）
|`policy.argmax`
|`target.gather`
|===

§1 手推里三者 stem:[y] 分别为 stem:[5.95] / stem:[5.455] / stem:[3.97]，可对照本节读图。

建议记录：`Q_mean`、`policy.max - target.max`、近 10 局回报、可选 Bellman 残差。

=== 4.3 怎么读图

* 回报差不多但 `Q_mean` 高很多 → 过估计嫌疑
* CartPole 下 stem:[\sum_{k=0}^{499}\gamma^k\approx 100] 量级；Q 长期远大于此要警惕
* 做消融时 soft/hard 更新策略应两侧一致，否则变量不干净

== 5. 三种损失：梯度在推什么？

*本节一句话：* DQN 改「分数表上的一格」；REINFORCE/PPO 改「选这个动作的概率」；PPO 还加了「一次别改太猛」的刹车。

[cols="1,2,2,2",options="header"]
|===
| |DQN |REINFORCE (+baseline) |PPO（本仓库）

|损失示意
|stem:[(Q_\theta(s,a)-y)^2]
|stem:[-A\log\pi_\theta(a\mid s)]
|stem:[-\min(rA,\,r_{\mathrm{clip}}A)+\cdots]

|stem:[y] / stem:[A]
|TD 目标（`no_grad`）
|回报或 stem:[G-V]
|GAE 的 stem:[A]、stem:[\hat{R}]（算死后固定）

|好动作
|抬高该格 stem:[Q]
|增大 stem:[\pi(a\mid s)]
|同左，但 clip 限幅

|坏动作
|压低该格 stem:[Q]
|减小 stem:[\pi]
|同左 + clip

|未选中动作
|本步不动（gather）
|经归一化间接变
|同左（Categorical）

|失败模式
|Q 虚高、目标抖
|方差爆炸
|ratio 炸、value 抢梯度
|===

*同状态冲突：* DQN 分别填 stem:[Q(s,\text{左})] / stem:[Q(s,\text{右})]；策略梯度改同一组 logits（此消彼长）；PPO 同向但有刹车。

== 6. 公式推导摘要

*本节一句话（进阶）：* 把前面的直觉写成贝尔曼方程、策略梯度和 GAE。零基础可跳过，需要时再回来。

=== 6.1 DQN

最优贝尔曼：

[stem]
++++
Q^*(s,a)=\mathbb{E}\big[r+\gamma\max_{a'}Q^*(s',a')\big]
++++

回归目标（经典）：stem:[y=r+\gamma\max_{a'}Q_{\theta^{-}}(s',a')]。 +
Double：stem:[a^*=\arg\max Q_\theta(s',\cdot)]，stem:[y=r+\gamma Q_{\theta^{-}}(s',a^*)]。 +
梯度只经 stem:[Q_\theta(s,a)]：stem:[\nabla L\propto(Q-y)\nabla Q]。

=== 6.2 策略梯度 → PPO

[stem]
++++
\nabla J=\mathbb{E}\Big[\sum_t\Psi_t\nabla\log\pi_\theta(a_t\mid s_t)\Big]
++++

[stem]
++++
r_t(\theta)=\exp(\log\pi_\theta-\log\pi_{\mathrm{old}})
++++

[stem]
++++
L^{\mathrm{CLIP}}=-\mathbb{E}\big[\min(r_t A_t,\,\mathrm{clip}(r_t,1-\varepsilon,1+\varepsilon)A_t)\big]
++++

[stem]
++++
L=L^{\mathrm{CLIP}}+c_v\|V-\hat{R}\|^2-c_e H[\pi]
++++

=== 6.3 GAE

[stem]
++++
\delta_t=r_t+\gamma V(s_{t+1})(1-d_t)-V(s_t)
++++

[stem]
++++
A_t=\delta_t+\gamma\lambda(1-d_t)A_{t+1}
++++

[stem]
++++
\hat{R}_t=A_t+V(s_t)
++++

stem:[\lambda\to 0]：偏置大方差小；stem:[\lambda\to 1]：近 MC；本实现 stem:[\lambda=0.95]。

== 8. 逐行精读：`compute_gae` + `ppo_update`

*本节一句话（进阶）：* 先算「每步比平均好多少」（GAE），再按 PPO 规则改策略和价值网。

文件：`cart-pole-ppo/ppo_train.py`。

=== 8.1 `compute_gae`（更新前，无梯度）

从 stem:[t=T-1] 倒到 stem:[0]：

. 初始 `next_value = last_value`（缓冲结束后当前状态的 stem:[V]）
. `delta = r + γ·next_value·(1-d) - V_t`
. `gae = delta + γλ·(1-d)·gae_未来`
. `next_value = values[t]`（倒序时对前一步而言的「下一状态 V」）
. 返回 `(A, A+V)`；后者作 Critic 的 `returns`

采集时的 stem:[V] 已固定 → 整个 `UPDATE_EPOCHS` 内 stem:[A]、stem:[\hat{R}] 当常数标签。

[NOTE]
====
同文件里的 `compute_returns`（折扣回报、遇 `done` 截断）*未*被训练主循环调用；仅保留供理解与 `test_ppo_helpers.py`。训练标签来自 `compute_gae` 返回的 stem:[A] 与 stem:[\hat{R}=A+V]，不是 Monte Carlo return。
====

=== 8.2 `ppo_update` 每个 epoch

[cols="2,3",options="header"]
|===
|代码 |作用

|`for UPDATE_EPOCHS`
|同批数据多用几次；靠 clip 限制偏离 stem:[\pi_{\mathrm{old}}]

|`logits, values = model(states)`
|现策略 + 现 stem:[V]

|`Categorical` / `log_prob(actions)`
|stem:[\log\pi_\theta(a_t\mid s_t)]

|`entropy`
|防过早塌缩

|`ratio = exp(new - old)`
|重要性比率

|`min(rA, clip(r)A)` 再取负 mean
|PPO 主损失

|`mse(values, returns)`
|Critic

|`- ENT_COEF * entropy`
|最大化熵

|`clip_grad_norm_(0.5)`
|防单步爆炸

|`optimizer.step()`
|Actor + Critic 一并更新
|===

*Clip 激活（单样本）：* stem:[A>0] 且 stem:[r>1+\varepsilon]（或对称坏动作情况）时，继续拉大 stem:[\pi] 不再降低该项损失。
第一 epoch 常 stem:[r\approx 1]；后面几个 epoch clip 才频繁生效。

*反传：* policy/entropy → actor；value → critic；`old_log_probs` / `advantages` / `returns` 无梯度。

== 10. 迷你数值速记

*DQN：* stem:[Q=2.0]，stem:[y=2.5] → 残差 stem:[+0.5] → 该动作 Q 升高。

*PPO：* stem:[A=1]，stem:[r=1] → 未裁剪；若更新后 stem:[r=1.3]、stem:[\varepsilon=0.2] → clipped 为 stem:[1.2]，`min` 刹车，不再奖励继续拉高。
